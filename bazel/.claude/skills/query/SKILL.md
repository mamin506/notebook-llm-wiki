# Query

## When to Use
- You need an answer about Bazel concepts, workflows, or troubleshooting
- You want to synthesize information from multiple wiki pages
- You notice a question that might deserve a new wiki page

## Procedure
1. Search the wiki index and identify the most relevant pages.
2. Read the candidate pages, note evidence, and flag contradictions or gaps.
3. Answer the question directly with clear citations to the wiki pages you used.
4. If the synthesis is valuable and not already covered, create a new page with proper frontmatter and add it to the index.
5. Record the query in wiki/log.md with the pages used, the answer, and any gaps discovered.

## Quality Checks
- The answer is clear, structured, and cites the most relevant pages.
- Uncertainty, contradictions, and missing coverage are called out.
- Valuable insights are either captured as a page or noted for follow-up.
